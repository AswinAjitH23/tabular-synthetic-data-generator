# tabular-synthetic-data-generator

A Python-based framework for generating high-quality synthetic tabular datasets using deep generative models such as CTGAN and TVAE.
 
## Features
 
- Generate synthetic tabular data from real datasets
- Preserve statistical properties of source data
- Configurable training parameters
- Synthetic data quality evaluation
- Easy integration into ML and testing workflows
 
## Supported Models
 
|     Model      |                      Description                              |
|----------------|---------------------------------------------------------------|
| CTGAN          | Conditional Tabular GAN for synthetic tabular data generation |
| TVAE           | Tabular Variational AutoEncoder                               |
| Future Support | CopulaGAN, GaussianCopula, Diffusion Models                   |
